# 项目需求

项目名称：（ZH）：Tibo今天说了啥？（EN）：What did Tibo say today?

我需要构建一个单页面Web应用，用来收录Tibo在X上的发言（https://x.com/thsottiaux），统计他当日的发言次数，并且接入AI的API判断他的发言是否有可能让codex重置。

接入API可以使用deepseek：

```
what_did_tibo_say_today
your-deepseek-api-key
```

重点观察他的发言中关于：

reset, there will be signs, celebrate, ship, again 相关的词汇，并且品尝他的含义，生成一个判断，是否codex/gpt work快要发生重置了

web是单界面应用，如果需要用脚手架，优先vue，不要其他花里胡哨的东西

## 2026-08 优化范围

1. 统计窗口从“当天”调整为滚动 7 天。
2. 除直接发言外，增加回复、引用和转推三类公开互动；点赞不作为沟通消息统计。
3. 数据源优先使用无需 X 登录的 FxTwitter API v2，Nitter RSS 作为降级来源。
4. 活动写入 SQLite，按 X status ID 幂等保存，并提供每日趋势与互动构成。
5. Codex / GPT Work 额度重置判断继续保留；纯转推不作为 Tibo 本人的原话送入分析。
6. 页面升级为响应式单页信号看板，并保留中英文切换。
7. 当前本地架构为 Express + SQLite；后续可迁移到 ChatGPT Sites + D1，详见 `docs/sites-migration.md`。
